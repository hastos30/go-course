status  - текущая информации состояния файлов (какие изменены, какие готовые к сохранению, какие не остелживаются) 
diff    - показывает построчную разницу между состояниями файлов или коммитов
add     - добавляет изменения из рабоей папки в индекс для подготовки к коммиту
commit  - фиксирует подготовленные изменения в локальном репозитории как отдельный снимок с описанием
log     - отображение всех коммитов
show    - показывает конкретную информацию об конкретном объекте git
restore - отменяет изменения в файлах (возвращает файл в рабочей папке к состоянию индекса/коммита или убирает его из индекса)
push    - отправка коммитов в удалённый репозиторий
pull    - забирает изменения из удалённого репозитория и сливает их с моей текущей веткой

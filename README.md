# Go Course: от нуля до Junior backend

Учебный репозиторий для изучения языка Go с нуля до уровня Junior backend-разработчика.

## Цель

Научиться писать, читать и проверять код на Go, понимать документацию и ошибки компилятора, обосновывать решения. В конце курса будет собственный backend-сервис на `net/http` и PostgreSQL для портфолио.

## Документы курса

- [PROGRESS.md](PROGRESS.md) — текущий статус, слабые места, история уроков
- [GLOSSARY.md](GLOSSARY.md) — словарь терминов по урокам

## Инструменты

- **Linux + zsh** — операционная система и командная оболочка
- **VS Code** — редактор кода со встроенным терминалом
- **Git** — система контроля версий, хранит историю изменений
- **GitHub** — хостинг репозитория, удалённая копия истории
- **Go** — язык программирования (версия 1.22+, точную выберем на уроке 2)

## Методика

Каждый урок состоит из 3–6 частей: объяснение, рабочий пример, запуск, проверка понимания. В конце урока даётся конспект и 3–5 задач (2–3 обязательные). Каждые 3–4 урока проводится контрольная без подсказок. Модуль заканчивается итоговой работой.

## Работа с Git

- Коммит делается после каждого законченного изменения.
- Сообщения коммитов пишутся по Conventional Commits на английском:
  - `feat` — новый код или функциональность
  - `fix` — исправление ошибки
  - `docs` — документация, прогресс, глоссарий
  - `test` — тесты
  - `refactor` — изменение структуры без смены поведения
  - `chore` — обслуживание (настройки, зависимости)

## Программа

### Часть 1. Фундамент Go — `part_1_foundation/`
- Модуль 1. Первый код и рабочие инструменты (уроки 1–5)
- Модуль 2. Управление потоком, функции и коллекции (уроки 6–13)
- Модуль 3. Типы, пакеты, файлы и тесты (уроки 14–19)

### Часть 2. Backend — `part_2_backend/`
- Модуль 4. Первый HTTP API и конкурентность (уроки 20–26)
- Модуль 5. SQL и PostgreSQL (уроки 27–31)
- Модуль 6. PostgreSQL в Go-приложении (уроки 32–38)
- Модуль 7. Безопасность, эксплуатация и выпуск (уроки 39–46)

### Часть 3. Самостоятельный проект — `part_3_capstone/`
- Модуль 8. Итоговый Go-сервис для портфолио

## Итоги модулей

- Модуль 1 — расчёт цены или перевод единиц
- Модуль 2 — `projects/todo_cli/`: задачи в памяти
- Модуль 3 — CLI с хранением в JSON и тестами
- Модуль 4 — `projects/todo_api/`: HTTP API с потокобезопасным хранилищем
- Модуль 5 — схема БД с JOIN, ограничениями и транзакциями
- Модуль 6 — API с PostgreSQL, миграциями и интеграционными тестами
- Модуль 7 — запуск через Docker Compose, тесты в CI
- Модуль 8 — итоговый сервис

## Критерии завершения курса

Собственный сервис на `net/http` и PostgreSQL: миграции, аутентификация и права доступа, пагинация и фильтрация, единые HTTP-ошибки, модульные, HTTP- и интеграционные тесты в CI, запуск через Docker Compose из чистого клона по README.

# Глоссарий

## Урок 1 — Настройка репозитория и документов курса

- terminal (терминал) — окно для управления компьютером текстовыми командами
- shell (оболочка) — программа внутри терминала, которая выполняет команды (у меня zsh)
- current directory (текущая папка) — папка, в которой сейчас работает терминал; показывает `pwd`
- home directory (домашняя папка) — личная папка пользователя, обозначается `~`
- alias (псевдоним) — короткое имя для длинной команды, например `la` вместо `ls -la`
- Git — система контроля версий, хранит историю изменений файлов
- repository (репозиторий) — папка, историю которой отслеживает Git (данные лежат в `.git`)
- commit (коммит) — сохранённый снимок изменений с сообщением, запись в истории
- staging area (область подготовки) — набор изменений, которые войдут в следующий коммит; заполняется `git add`
- branch (ветка) — линия истории коммитов; основная называется `main`
- local repository (локальный репозиторий) — репозиторий на моём компьютере
- remote repository (удалённый репозиторий) — копия репозитория на сервере, например на GitHub
- Markdown — разметка текста обычными символами (`#`, `-`, `**`), файлы `.md`
- untracked file (неотслеживаемый файл) — файл в папке репозитория, за которым Git пока не следит
- hash (хеш) — уникальный идентификатор коммита, например `f7ff181`
- HEAD — указатель на текущее положение в истории (обычно на последний коммит текущей ветки)
- origin — стандартное имя основного удалённого репозитория
- push (отправка) — передача локальных коммитов в удалённый репозиторий
- SSH key (SSH-ключ) — пара ключей для входа без пароля: приватный хранится у меня, публичный отдаётся GitHub
- Conventional Commits — соглашение о сообщениях коммитов: `тип: описание` (`docs`, `feat`, `fix` и др.)

## Урок 2 — Первая программа

- compiler (компилятор) — программа, которая переводит код на Go в машинный код до запуска
- binary (бинарник) — исполняемый файл, результат сборки; запускается без Go
- toolchain (набор инструментов) — компилятор и команда `go` с подкомандами (`run`, `build`, `fmt`, `doc`)
- PATH (путь поиска) — список папок, где терминал ищет команды
- module (модуль) — набор Go-кода с общим именем, описан в `go.mod`
- module path (путь модуля) — имя модуля, обычно адрес репозитория: `github.com/hastos30/go-course`
- package (пакет) — группа `.go`-файлов в одной папке; `package main` — программа
- import (импорт) — подключение пакета, например `import "fmt"`
- standard library (стандартная библиотека) — пакеты, которые идут вместе с Go (`fmt`, `os` и др.)
- function (функция) — именованный блок команд; объявляется `func`
- entry point (точка входа) — место, откуда начинается выполнение: `func main()`
- string (строка) — текст в двойных кавычках, например `"Hello, world!"`
- comment (комментарий) — текст после `//`, который компилятор пропускает
- compilation error (ошибка компиляции) — ошибка, найденная до запуска; программа не собирается
- EOF (end of file, конец файла) — компилятор дошёл до конца файла, а код не закончен
- gofmt — стандартный форматировщик Go; `go fmt ./...` форматирует все пакеты
- gopls — языковой сервер Go: подсказки и ошибки прямо в VS Code

## Урок 3 — Переменные и типы

- variable (переменная) — именованная ячейка памяти со значением определённого типа
- type (тип) — вид данных, который определяет допустимые значения и операции; у переменной закреплён навсегда
- declaration (объявление) — создание переменной или константы: `var age int = 25`
- assignment (присваивание) — запись нового значения в существующую переменную: `age = 26`; правая часть вычисляется первой
- int (целое число) — тип целых чисел: `42`, `-7`
- float64 (число с плавающей точкой) — тип дробных чисел, дробь через точку: `3.14`
- bool (логический тип) — тип со значениями `true` и `false`
- zero value (нулевое значение) — значение переменной без начального значения: `0`, `0`, `""`, `false`
- short variable declaration (короткое объявление переменной) — `name := value`, только внутри функции, создаёт новую переменную
- type inference (вывод типа) — Go сам определяет тип по значению: `2026` → `int`, `21.5` → `float64`
- literal (литерал) — значение, записанное прямо в коде: `25`, `"Kyiv"`, `true`
- constant (константа) — именованное значение, известное при компиляции; изменить нельзя: `const pi = 3.14159`
- untyped constant (нетипизированная константа) — константа без указанного типа; в выражении принимает тип другого операнда: `float64(x) * 15` → 15 становится `float64`
- typed constant (типизированная константа) — константа с явным типом: `const p int = 15`; с `float64` уже не смешивается
- flow of execution (ход выполнения) — порядок выполнения команд: в `main` сверху вниз
- increment (инкремент) — увеличение на 1: `age++`

## Урок 4 — Вычисления и вывод

- operator (оператор) — знак действия: `+`, `-`, `*`, `/`, `%`
- expression (выражение) — то, что вычисляется в значение: `a + b*2`
- operator precedence (приоритет операторов) — порядок вычисления: сначала `*` `/` `%`, потом `+` `-`; скобки меняют порядок
- compound assignment (сокращённое присваивание) — `x += 5` то же, что `x = x + 5`; также `-=`, `*=`, `/=`
- integer division (целочисленное деление) — деление `int` на `int`, дробная часть отбрасывается в сторону нуля: `7/2 = 3`
- remainder (остаток) — оператор `%`, остаток от целочисленного деления: `7 % 2 = 1`; только для целых
- runtime error (ошибка времени выполнения) — ошибка, которая возникает при работе программы, а не при компиляции
- panic (паника) — аварийная остановка программы при runtime error, например `integer divide by zero`
- type conversion (преобразование типа) — создание значения другого типа: `float64(x)`, `int(y)`; исходная переменная не меняется
- format string (строка формата) — шаблон для `Printf` с глаголами: `"Age: %d\n"`
- verb (глагол форматирования) — место подстановки в строке формата: `%d`, `%f`, `%s`, `%t`, `%v`, `%T`
- precision (точность) — число знаков после точки: `%.2f`; при выводе округляет
- newline (перевод строки) — `\n`; `Printf` не добавляет его сам
- go vet — анализатор, который находит подозрительный, но компилируемый код (например, глагол не того типа)

## Урок 5 — История изменений в Git

- working tree (рабочая папка) — файлы на диске, которые я правлю в VS Code
- index (индекс) — другое название staging area; `git add` кладёт туда снимок файла
- tracked file (отслеживаемый файл) — файл, который уже есть хотя бы в одном коммите
- staged (подготовленный) — изменение лежит в staging area и войдёт в следующий коммит
- modified (изменённый) — отслеживаемый файл отличается от версии в коробке или коммите
- diff (разница) — построчное сравнение двух версий: `-` удалено, `+` добавлено
- hunk (фрагмент изменений) — блок diff, начинается с `@@ -4,6 +4,6 @@`
- pager (программа постраничного просмотра) — показывает длинный вывод Git; выход клавишей `q`
- git restore — возвращает файл на диске к версии из staging area; незакоммиченные правки пропадают навсегда
- unstage (убрать из подготовки) — `git restore --staged <файл>`, правка остаётся на диске
- git log — история коммитов; `--oneline`, `-N`, `--stat`, `-- <путь>`
- git show — один коммит: сообщение и его diff
- HEAD~N — коммит на N шагов раньше HEAD: `HEAD~1`, `HEAD~2`
- origin/main — память Git о ветке на GitHub на момент последнего обмена
- ahead / behind (впереди / позади) — сколько коммитов есть только локально или только на GitHub
- fetch (получение) — `git fetch` скачивает новые коммиты и обновляет `origin/main`, файлы не меняет
- pull (подтягивание) — `git pull` = `fetch` + обновление моей ветки и файлов
- fast-forward (перемотка вперёд) — обновление ветки простым сдвигом вперёд, когда у меня нет своих новых коммитов

## Урок 6 — Условия

- comparison operator (оператор сравнения) — `== != < <= > >=`, сравнивает два значения одного типа и даёт `bool`
- boolean expression (логическое выражение) — выражение, результат которого `true` или `false`
- expression (выражение) — код, который даёт значение: `age == 18`, `a + b`
- statement (инструкция) — действие без значения: присваивание `x = 5`, `if`; нельзя передать в функцию
- block (блок) — код в `{ }`; переменные из блока снаружи не видны
- if / else / else if — выполняет ветку по условию; из цепочки срабатывает первая ветка с `true`
- logical operator (логический оператор) — `&&` (И), `||` (ИЛИ), `!` (НЕ)
- short-circuit evaluation (сокращённое вычисление) — `false && …` и `true || …` не вычисляют правую часть
- switch (переключатель) — выбор ветки по значению; `case 1, 2:` — любое из значений, `default` — иначе, `break` не нужен
- shadowing (затенение) — `:=` в блоке создаёт новую переменную с тем же именем, внешняя не меняется
- lossless conversion (преобразование без потерь) — `float64(intValue)`; `int(floatValue)` теряет дробь

## Урок 7 — Цикл for

- loop (цикл) — код, который выполняется повторно, пока условие `true`; в Go есть только `for`
- iteration (итерация) — один проход тела цикла
- counter (счётчик) — переменная, которая считает проходы, обычно `i`
- init statement (инструкция инициализации) — `i := 1` в `for`, выполняется один раз перед циклом; переменная видна только внутри цикла
- condition (условие цикла) — проверяется перед каждой итерацией; `false` завершает цикл
- post statement (инструкция после итерации) — `i++`, `i -= 3`, выполняется после каждого прохода тела
- infinite loop (бесконечный цикл) — `for { }` без условия; остановить программу — Ctrl+C
- break (прервать) — сразу выходит из цикла целиком
- continue (продолжить) — пропускает остаток тела и переходит к следующей итерации
- off-by-one error (ошибка на единицу) — цикл делает на один проход больше или меньше нужного, обычно из-за `<` и `<=`
- parallel assignment (параллельное присваивание) — `a, b = b, a`: сначала вычисляется вся правая часть, потом присваивание

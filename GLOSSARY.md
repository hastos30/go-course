# Глоссарий

## Урок 1 — Настройка репозитория и документов курса

- terminal (терминал) — окно для управления компьютером текстовыми командами
- shell (оболочка) — программа внутри терминала, которая выполняет команды (у меня zsh)
- current directory (текущая папка) — папка, в которой сейчас работает терминал; показывает `pwd`
- home directory (домашняя папка) — личная папка пользователя, обозначается `~`
- alias (псевдоним) — короткое имя для длинной команды, например `la` вместо `ls -la`
- Git — система контроля версий, хранит историю изменений файлов
- repository (репозиторий) — папка, историю которой отслеживает Git (данные лежат в `.git`)
- commit (коммит) — сохранённый снимок изменений с сообщением, запись в истории
- staging area (область подготовки) — набор изменений, которые войдут в следующий коммит; заполняется `git add`
- branch (ветка) — линия истории коммитов; основная называется `main`
- local repository (локальный репозиторий) — репозиторий на моём компьютере
- remote repository (удалённый репозиторий) — копия репозитория на сервере, например на GitHub
- Markdown — разметка текста обычными символами (`#`, `-`, `**`), файлы `.md`
- untracked file (неотслеживаемый файл) — файл в папке репозитория, за которым Git пока не следит
- hash (хеш) — уникальный идентификатор коммита, например `f7ff181`
- HEAD — указатель на текущее положение в истории (обычно на последний коммит текущей ветки)
- origin — стандартное имя основного удалённого репозитория
- push (отправка) — передача локальных коммитов в удалённый репозиторий
- SSH key (SSH-ключ) — пара ключей для входа без пароля: приватный хранится у меня, публичный отдаётся GitHub
- Conventional Commits — соглашение о сообщениях коммитов: `тип: описание` (`docs`, `feat`, `fix` и др.)

## Урок 2 — Первая программа

- compiler (компилятор) — программа, которая переводит код на Go в машинный код до запуска
- binary (бинарник) — исполняемый файл, результат сборки; запускается без Go
- toolchain (набор инструментов) — компилятор и команда `go` с подкомандами (`run`, `build`, `fmt`, `doc`)
- PATH (путь поиска) — список папок, где терминал ищет команды
- module (модуль) — набор Go-кода с общим именем, описан в `go.mod`
- module path (путь модуля) — имя модуля, обычно адрес репозитория: `github.com/hastos30/go-course`
- package (пакет) — группа `.go`-файлов в одной папке; `package main` — программа
- import (импорт) — подключение пакета, например `import "fmt"`
- standard library (стандартная библиотека) — пакеты, которые идут вместе с Go (`fmt`, `os` и др.)
- function (функция) — именованный блок команд; объявляется `func`
- entry point (точка входа) — место, откуда начинается выполнение: `func main()`
- string (строка) — текст в двойных кавычках, например `"Hello, world!"`
- comment (комментарий) — текст после `//`, который компилятор пропускает
- compilation error (ошибка компиляции) — ошибка, найденная до запуска; программа не собирается
- EOF (end of file, конец файла) — компилятор дошёл до конца файла, а код не закончен
- gofmt — стандартный форматировщик Go; `go fmt ./...` форматирует все пакеты
- gopls — языковой сервер Go: подсказки и ошибки прямо в VS Code

## Урок 3 — Переменные и типы

- variable (переменная) — именованная ячейка памяти со значением определённого типа
- type (тип) — вид данных, который определяет допустимые значения и операции; у переменной закреплён навсегда
- declaration (объявление) — создание переменной или константы: `var age int = 25`
- assignment (присваивание) — запись нового значения в существующую переменную: `age = 26`; правая часть вычисляется первой
- int (целое число) — тип целых чисел: `42`, `-7`
- float64 (число с плавающей точкой) — тип дробных чисел, дробь через точку: `3.14`
- bool (логический тип) — тип со значениями `true` и `false`
- zero value (нулевое значение) — значение переменной без начального значения: `0`, `0`, `""`, `false`
- short variable declaration (короткое объявление переменной) — `name := value`, только внутри функции, создаёт новую переменную
- type inference (вывод типа) — Go сам определяет тип по значению: `2026` → `int`, `21.5` → `float64`
- literal (литерал) — значение, записанное прямо в коде: `25`, `"Kyiv"`, `true`
- constant (константа) — именованное значение, известное при компиляции; изменить нельзя: `const pi = 3.14159`
- untyped constant (нетипизированная константа) — литерал или константа без указанного типа; Go подбирает тип по месту использования
- flow of execution (ход выполнения) — порядок выполнения команд: в `main` сверху вниз
- increment (инкремент) — увеличение на 1: `age++`
